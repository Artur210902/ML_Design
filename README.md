# ML_Design — агентный harness для аудита безопасности репозиториев

Проектный репозиторий курса по дизайну ML-систем. Тема — система автоматического аудита
безопасности репозиториев с ИИ-сгенерированным кодом: детерминированные сканеры как
генератор кандидатов, языковая модель как верификатор.

## Проблема

От 25% до 45% ИИ-сгенерированного кода содержит уязвимости, а проверять его нечем:
ручной аудит стоит 5–30 тыс. долларов и занимает недели, а у статических сканеров доля
ложных срабатываний в промышленном коде превышает 90%. Дешёвые инструменты шумят,
точные — дороги.

## Идея решения

Профили двух подходов зеркальны, и это измерено:

| Подход | Precision | Recall |
|---|---|---|
| Детерминированные сканеры | 0.669 | 0.790 |
| LLM без инструментов (по литературе) | 0.800 | 0.103 |

Сканеры находят почти всё, но много ошибаются; модель почти не ошибается, но находит мало.
Отсюда архитектура: **сканер отбирает кандидатов, модель отсеивает ложные**.

## Главный проверяемый результат

Сравнение четырёх конфигураций на одних репозиториях, одной модели и одном бюджете:

| # | Конфигурация | Статус |
|---|---|---|
| 1 | Только детерминированные инструменты | измерена |
| 2 | Инструменты + LLM-верификатор | в разработке |
| 3 | LLM без инструментов | запланирована |
| 4 | Сторонний открытый харнес на той же модели | запланирована |

**Δ(2−1)** — вклад модели. **Δ(2−3)** — вклад инструментов и оркестрации.

Метрики считаются **снаружи** системы, чтобы она не могла влиять на собственную оценку.

## Текущие результаты

| Эталон | Precision | Recall | F1 |
|---|---|---|---|
| OWASP Benchmark 1.2 (строгое равенство CWE) | 0.669 | 0.790 | **0.725** |
| Собственный seeding-набор (20 уязвимостей, 15 CWE) | 0.302 | 0.800 | **0.438** |

Для сравнения, опубликованные на том же эталоне результаты: Semgrep CE F1 = 0.694,
CodeQL F1 = 0.744. Наши числа того же порядка, то есть методика сопоставления корректна;
прямым сравнением инструментов это не является, поскольку набор правил вендоренный.

Дополнительно: изоляция песочницы выдержала 7 враждебных сценариев из 7 при работающей
канарейке, воспроизводимость трёх прогонов — 1.000.

## Разработка

Требуется Python 3.12+.

```bash
pip install ruff pre-commit
pre-commit install
```

### Проверки

```bash
ruff check .      # линтер
ruff format .     # форматер
pre-commit run --all-files
```

Хуки `pre-commit` запускаются перед каждым коммитом: ruff (линтер и форматер), проверка
YAML/TOML/JSON, поиск приватных ключей, gitleaks, запрет прямых коммитов в `main`.
Поиск секретов включён сознательно — для проекта про безопасность это уместно.
